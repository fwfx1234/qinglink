# QingLink 协议 v2

服务发现使用 UDP `3723` 广播请求，响应包含 `id`、`name`、`version=2`、`port` 和 `pairing`。

未认证端点：

- `GET /api/v2/health`
- `POST /api/v2/pairing/requests`
- `POST /api/v2/pairing/confirm`
- `DELETE /api/v2/pairing/requests/{request_id}`

已认证控制使用 `WS /api/v2/events`；高频指针输入使用 `WS /api/v2/input`。每个 JSON 命令都包含 `request_id`，响应使用 `{type, request_id, data|error}`。

远程输入在普通桌面上使用 `send_text` 提交 UTF-8 文本，使用 `key_event` 发送 HID usage 事件（`usage`、`modifiers`、`pressed`）。Windows 安全桌面有意拒绝 Unicode 文本；客户端应在此处使用标准键盘 usage。鼠标移动保持 12 字节二进制帧，而按钮和滚轮命令在两种桌面路径上都可用。

安全桌面控制增加了 `get_secure_desktop_status`、`secure_attention` 和 `send_secure_ascii`。后者仅接受可打印 ASCII 并通过活动的 Windows 键盘布局映射；它从不使用剪贴板。安全注意命令受服务器速率限制，仅对已认证的已配对设备可用。当前 v2 传输在本地网络上仍为 WS/HTTP；在添加 TLS/WSS 之前，部署必须将网络视为可信的。

对于 UAC 和安全桌面交互，客户端应：
1. 轮询 `get_secure_desktop_status` 以检测桌面何时切换到 `uac` 或 `winlogon`。
2. 在 UAC 对话框上使用 `mouse_move_absolute` 进行精确按钮点击，因为相对 `mouse_move` 无法可靠地定位特定屏幕坐标。
3. 在安全桌面上使用带标准 HID usage 的 `key_event` 进行键盘输入；`send_text` 在此处被拒绝。
4. `secure_desktop_status` 响应包含 `uac_detected` 和 `token_integrity_level` 字段，以帮助客户端决定当前令牌是否可以进行 UAC 交互。

在 Windows 10/11 x64 上，监听器和令牌存储由自动 LocalSystem `QingLinkService` 拥有。持久化数据存储在 `%ProgramData%\QingLink` 中；其目录 ACL 仅向 SYSTEM 和内置管理员组授予完全访问权限。服务为活动的控制台 WTS 会话维护一个输入代理，不注入到其他用户会话中。现有令牌可以在登录前进行身份验证。创建新配对仍然是桌面确认的操作，不作为无人值守的登录前注册路径暴露。

## 配对

手机创建请求并保留返回的标识符，同时 PC 显示验证码：

```json
POST /api/v2/pairing/requests
{"device_id":"mobile-...","device_name":"轻联手机"}

{"request_id":"uuid","expires_at_unix":0}
```

手机在 60 秒截止时间前确认验证码。成功响应包含稳定的 PC 标识和长期令牌；令牌由移动应用存储在平台安全存储中。

```json
POST /api/v2/pairing/confirm
{"request_id":"uuid","pin":"123456","device_id":"mobile-...","device_name":"轻联手机"}

{"token":"...","pc_id":"...","pc_name":"办公室电脑","mac_address":"AA:BB:CC:DD:EE:FF","wake_networks":[{"mac_address":"AA:BB:CC:DD:EE:FF","ipv4_address":"192.168.1.42","prefix_length":24,"broadcast_address":"192.168.1.255"}]}
```

配对错误使用稳定错误码：`PAIRING_NOT_FOUND`、`PAIRING_EXPIRED`、`INVALID_PIN`、`RATE_LIMITED`、`DEVICE_MISMATCH`。

## UDP 发现

客户端向局域网广播 UDP `3723` 的 `qinglink-discover-v1` 请求。服务仅在 TCP `3721` 就绪时响应 JSON，包含持久化 `id`、显示名称、协议版本和 TCP 端口。客户端按 `id` 去重，并在 PC 更换网络时替换地址。

## 认证

配对后，两个 WebSocket 通道都需要令牌认证消息。旧版 PIN 认证消息和所有 `/api/v1/*` 端点有意不被支持。
